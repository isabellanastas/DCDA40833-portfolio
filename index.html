Semester Reflection

What I learned: Over the course of this class, I learned a lot more about building and managing a website than I expected. At the beginning of the semester, I only had a small amount of experience with HTML and CSS, so creating a full portfolio site felt a little intimidating. As I worked through the labs, I learned how to structure pages, link navigation across the site, and add different types of interactive features. I also gained experience using tools like Mapbox, Tableau, GitHub Pages, and Python to create visualizations and maps that could be embedded directly into my site. Seeing everything come together on one website helped me understand how these different tools can work together to present data and ideas clearly.

Challenges I overcame: One of the biggest challenges I faced was the technical side of some of the assignments. Coding does not always come naturally to me, so there were definitely times when things did not work the way I expected. For example, getting visualizations to display properly or troubleshooting layout issues sometimes took a lot of trial and error. I also struggled at times with understanding how different files connected to each other within GitHub and my site structure. However, I learned that a lot of coding is simply problem solving. I spent time testing small changes, looking up examples, and using tools like GitHub’s AI suggestions or ChatGPT to better understand what I was doing. Over time, this made the process feel much less overwhelming.

How I grew: Through these labs, I feel like I grew in both confidence and technical understanding. Even though I am not an expert coder, I am much more comfortable editing HTML, adjusting CSS, and adding new features to my site. I also learned how to think more about design and user experience, like making sure navigation works across pages and keeping the visual style consistent. Building a portfolio also helped me see how technical work can be presented in a clear and organized way.

Looking ahead: Looking ahead, I think this site will continue to be useful as I add more projects or update it over time. I would like to keep improving the design and maybe add additional visualizations or interactive elements as I learn more. Overall, this class helped me realize that even if coding feels challenging at first, it becomes much easier with practice and experimentation. I am glad I now have a portfolio that shows the different projects I worked on this semester and the skills I developed along the way.

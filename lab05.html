Reflection

Technical Understanding

For this assignment, I used GitHub’s AI feature to generate and edit code in my website. I asked it to do three main things: add a light/dark mode toggle, create a simple tennis visualization with two characters playing, and fix some structural problems with my hamburger menu while improving the color scheme.

For the light/dark mode toggle, the AI generated JavaScript and CSS and added a button to switch between themes. The button changes the colors through CSS. I understand the general idea that clicking the button changes the styling, but I wouldn’t say I fully understand every line of the JavaScript. I mostly understand it conceptually rather than at a deeper coding level.

For the tennis visualization, the AI created a simple animation using CSS. I didn’t fully understand how those values were chosen or how the animation looped smoothly. I had to read through the code multiple times to get a basic understanding of what was happening. I still don’t think I could recreate it completely on my own without help.

When I asked the AI to fix my hamburger menu and improve the color scheme, it reorganized some of my HTML and adjusted spacing in the CSS. Some of the fixes worked immediately, but others slightly broke my layout. I had to experiment and undo parts of what it generated. This made me realize that even if the code looks right, I don’t always understand why something works or doesn’t work.

Process Evaluation

AI was most helpful in speeding things up. It saved me time by generating structure that would have taken me much longer to write myself. It also helped me troubleshoot layout problems more quickly than I probably could have alone.

At the same time, it was problematic when it assumed too much about my project structure or gave me more complex solutions than I needed. Sometimes I felt like I was copying code before fully understanding it, so I had to examine it to understand when I wanted to accept versus reject the code.

My role in this process was deciding what I wanted the outcome to look like and testing whether the code actually worked. Even if I didn’t understand everything technically, I still had to evaluate if it matched my vision and functioned properly. AI generated options, but I still had to make decisions.

Ethical & Pedagogical Considerations

I think vibe coding can help my development if I use it carefully. It allows us to incorporate code that we haven’t learned yet. However, it can be easy to rely on it too heavily without trying to understand the logic.

In an academic setting, I think proper credit means clearly stating that I used GitHub AI to generate and revise parts of my code. I shouldn’t present it as entirely my own work if it wasn’t.

Going forward, I plan to use AI for support and debugging, but I want to push myself to understand the basics before relying on it.
